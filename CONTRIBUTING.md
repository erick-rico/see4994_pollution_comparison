# Contributing Guidelines

Thank you for your interest in contributing!  
Although this repository represents a personal guided-study project, contributions
and suggestions are welcome — especially from researchers or students working on
air quality, meteorology, or synoptic climatology.

---

## 📌 How to Contribute

### 1. Reporting issues
If you find bugs, errors, or unclear descriptions, please open an **Issue** on GitHub.

### 2. Suggesting improvements
You may submit:
- Improvements to code clarity
- Better visualization approaches
- Additional meteorological diagnostics
- Data quality checks
- Literature suggestions

### 3. Pull Requests (PRs)
If submitting a PR:
- Fork the repository.
- Create a branch for your changes.
- Include a clear description of what you fixed or improved.
- Keep style and directory structure consistent.

---

## 📘 Data Availability
The cleaned Mexico City dataset is not included in the repository because it was manually processed from many separate files.
If you need the cleaned CSV for academic purposes, feel free to contact me directly.

Hong Kong data is publicly available from the EPD/AQHI website.

---

## 🤝 Attribution
If you use ideas, figures, or parts of the workflow, please **cite the repository**
(see `CITATION.cff`).

This project will be extended into future work, including potential publication and
thesis development.

---

Thank you for supporting open science and atmospheric research!
